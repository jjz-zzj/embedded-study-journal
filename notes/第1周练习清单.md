## 编译命令速查（背下来）

```bash
gcc -Wall -Wextra -g -o hello hello.c     # 编译
./hello                                    # 运行
```



| 选项         | 作用            |
| ---------- | ------------- |
| `-Wall`    | 打开常用警告        |
| `-Wextra`  | 打开额外警告        |
| `-g`       | 加调试信息（gdb 要用） |
| `-o hello` | 指定输出文件名       |

> **每次编译都带上 `-Wall -Wextra -g`。警告不是噪音，是编译器在救你。**

### P1 · 个人信息卡片

读取姓名、年龄、身高（米）、学号，格式化输出成对齐的卡片。

**思路提示**

- 用 `scanf("%19s", name)` 读字符串（注意长度限制）
- 用 `%5d` 控制宽度右对齐，`%-10s` 左对齐
- 身高用 `%.2f` 保留两位

**自问**：如果姓名超过 19 个字符会发生什么？

### P2 · 类型字节数探测器

用 `sizeof` 打印所有基本类型的字节数，并输出 `int` 的最大/最小值。

**思路提示**

- `#include <limits.h>`，使用 `INT_MAX`、`INT_MIN`
- `sizeof` 的结果用 `%zu` 打印，不要用 `%d`

**自问**：你的机器上 `long` 是几字节？为什么 Windows 和 Linux 上可能不一样？

### P3 · 圆的几何计算

输入半径，输出周长和面积（保留 3 位小数）。

**思路提示**

- `#define PI 3.1415926`
- **关键坑**：`1/2` 等于多少？`1.0/2` 等于多少？整数除法和浮点除法完全不同

**自问**：为什么 `4/3 * PI * r * r * r` 算球体积会算错？

### P4 · 温度换算表

输出 -20℃ 到 50℃ 的换算表，每 5 度一行。

**思路提示**

- `for (int c = -20; c <= 50; c += 5)`
- 华氏度 = 摄氏 × 9.0 / 5.0 + 32（**写 9.0 不要写 9**）

**自问**：写成 `9 / 5` 结果会变成什么？

输入两个数和一个运算符，输出运算结果。

## 周末挑战（P8）

### P8 · 8 位"寄存器"位操作

```
输入一个 0-255 的十进制数
输出它的二进制表示（8 位，如 00001010）
然后把第 3 位置 1，再次输出二进制和十进制值
```

**思路提示**

- 取第 n 位：`(reg >> n) & 1`  
  |  |  |  
  | --- | --- |
- 置位：`reg |= (1 << 3)`
- 清位：`reg &= ~(1 << 3)`
- 输出二进制：从高位到低位循环取位（第 7 位到第 0 位）
- **别用 `itoa`**（非标准函数），手写循环
- 用 `unsigned char` 类型存寄存器值

**这道题为什么重要**

这三行代码就是你未来配置 STM32 寄存器的**全部套路**：

```c
GPIOA->ODR |=  (1 << 5);    // PA5 输出高电平（点亮 LED）
GPIOA->ODR &= ~(1 << 5);     // PA5 输出低电平（熄灭 LED）
if (GPIOA->IDR & (1 << 3))   // 读取 PA3 的输入状态
```

做完这道题，你就理解了嵌入式最核心的操作方式。

## 记忆要点

> - **每次编译都加 `-Wall -Wextra -g`**
> - **读字符串必须限制长度**：`scanf("%19s", buf)`
> - **永远不用 `gets()`**
> - **整数除法会截断**：要浮点结果就写 `9.0 / 5.0`  
>   |  |  |  
>   | --- | --- |
> - **寄存器操作三件套**：`|=` 置位、`&=~` 清位、`&` 取位
