# 嵌入式方向 C 语言学习计划（定制版）

> **你的情况**：中南大学测控专业大四 · C 语言几乎零基础 · 手头无任何开发板 · 每天 2 小时以上 · 方向未定

## 一、先说现实：你需要调整预期

按"零基础 + 2 小时/天 + 无硬件"这三个条件算，你大概需要 **5-6 个月**才能到"能独立干活"的水平。这意味着：

**明年 3-4 月春招时，你大概率处于"基础扎实 + 刚入门嵌入式"的状态。**

这不是坏消息，但你得换打法：

| 时间窗口 | 定位 | 目标 |
|---------|------|------|
| 2027.03-04 春招 | **练兵 + 捡漏** | 投中小公司、初创，重点是真实感受面试问什么，攒经验，别指望一次上岸 |
| 2027.05-08 | **主战场** | 此时你基础扎实 + 有成型项目，是真正有竞争力的时点 |
| 毕业后 | 社招补录 | 兜底 |

### 三个必须现在做的动作

1. **立刻去争取嵌入式方向的毕设题目。** 这是你能拿到的最好的跳板——有老师指导、有学分要求、还能当求职项目。测控专业找这类题目不难。
2. **方向默认先走 MCU。** 理由：岗位数量最多、出成果最快、和你测控背景最对口。第 12 周我们再花一周做"分叉验证"确认。
3. **硬件在第 12 周左右下单即可，不用现在买。** 前 10 周没板子反而是好事——见下节。

## 二、为什么前 10 周无硬件反而是优势

新手一上来就折腾开发板，时间会大量耗在这些事情上：

- ST-Link 驱动装不上、设备管理器里带感叹号
- 杜邦线接触不良，以为是代码 bug
- 串口助手乱码，查半天是波特率设错
- 下载失败、芯片锁死

**这些和编程能力毫无关系，却最消耗新手的耐心。**

前 10 周在 PC 上纯练 C，你可以把 100% 的注意力放在"程序逻辑"和"内存发生了什么"上——这才是后面一切的根基。等你有了扎实基础再上板子，那些硬件坑半天就能踩完。

### 无硬件期间如何保持"嵌入式感"

纯 `printf` 练语法很容易枯燥。这几个方法能让你在没有板子的情况下，练到贴近嵌入式的思维方式：

| 练法 | 怎么做 | 练到什么 |
|------|--------|---------|
| **寄存器模拟器** | 用 `struct` + 位域定义一组"假寄存器"，用位运算做置位/清位/取位 | 这正是真实嵌入式操作寄存器的方式 |
| **传感器报文解析** | 手写解析器解析 NMEA-0183（GPS）或 SHT30 数据帧 | 串口协议解析、字符串处理、校验和 |
| **状态机实现** | 用 `switch` + 状态枚举实现按键消抖、命令解析器 | 嵌入式最核心的编程范式 |
| **环形缓冲区** | 实现 ring buffer，配套单元测试 | 中断与主线程数据交换的标配结构 |
| **LED 点阵模拟** | 用二维字符数组模拟 8×8 点阵，`printf` 输出图案 | 建立"代码 → 可见反馈"的连接 |
| **在线仿真** | Wokwi（wokwi.com）浏览器里仿真 Arduino / ESP32 / RP2040，免费 | 提前感受写代码控制硬件 |

> Wokwi 对 STM32 的支持情况请以官网为准，不确定时先用 Arduino/ESP32 模式体验即可，目的是建立感觉，不是学具体平台。

## 三、阶段一：语法地基（第 1-5 周）

> 零基础，所以给足 5 周，不赶进度。**这一阶段唯一目标：让手不抵触键盘。**

### 第 1 周 · 环境与第一个程序

**任务**
- 搭建 gcc 环境（见附录）
- 理解"编译 → 链接 → 运行"这条链路
- 数据类型：`int / char / float / double`、各类型占多少字节
- `printf` 格式控制：`%d %c %f %x %p`
- `scanf` 输入

**练习**
- `hello.c`：打印个人信息
- 用 `sizeof` 打印所有基本类型的字节数
- 计算圆的面积/周长
- 温度换算（摄氏 ↔ 华氏）

**自检**：能说清 `#include <stdio.h>` 是干什么的、`main` 为什么返回 `int`。

---

### 第 2 周 · 运算符与分支

**任务**
- 算术、关系、逻辑、位、赋值运算符
- **运算符优先级**（别背，用括号）
- 隐式类型转换与强制转换
- `if / else if / else`、`switch-case`
- 三目运算符

**练习**
- 判断闰年
- 三个数排序
- 成绩等级转换（if 版 + switch 版各写一遍）
- 简单计算器

**自检**：能解释 `a = b == c` 为什么不是你想的意思。

---

### 第 3 周 · 循环与数组

**任务**
- `while / do-while / for`、`break / continue`
- 一维数组、二维数组
- 数组与循环的配合
- 数组越界的后果（**这是 UB，必须知道**）

**练习**
- 九九乘法表
- 素数判断（100 以内）
- 冒泡排序、选择排序
- 斐波那契数列（循环版）
- 矩阵转置

**自检**：能说清 `arr[5]` 里访问 `arr[5]`（第6个元素）会发生什么。

---

### 第 4 周 · 函数与递归

**任务**
- 函数定义、声明、调用
- **值传递 vs 地址传递**（先建立概念，第 6 周深挖）
- 递归思想与终止条件
- 变量作用域、生命周期
- `static` 局部变量

**练习**
- 用函数重写前 3 周所有练习
- 阶乘、汉诺塔（递归）
- 二分查找（递归 + 循环两版）
- 数组作为函数参数传递

**自检**：能画出递归调用时栈的变化。

---

### 第 5 周 · 字符串与结构体入门

**任务**
- 字符数组与字符串、`'\0'` 结束符
- **手写实现** `strlen / strcpy / strcmp / strcat`（不许用库函数）
- 结构体定义与使用、`.` 与 `->`
- 结构体数组

**练习**
- 统计字符串中各类字符个数
- 字符串反转
- 判断回文
- **学生成绩管理系统 v1.0**（结构体数组 + 排序 + 查询）

**⚠️ 安全提醒（嵌入式面试必考点）**
`strcpy` / `strcat` / `sprintf` / `gets` 都不检查目标缓冲区长度，是缓冲区溢出漏洞的头号来源。练习手写实现是为了理解原理，**实际工程中一律使用带长度限制的版本**（`strncpy`、`snprintf`），并记得手动补 `'\0'`。

### 阶段一验收
关掉所有资料，2 小时内独立完成"学生成绩管理系统"：录入、查询、排序、保存文件、加载文件。不崩溃、无警告。

## 四、阶段二：指针与内存（第 6-11 周）

> **这是 C 语言的分水岭，也是嵌入式面试考点最密集的区域。** 零基础在这儿卡壳是 100% 正常的，硬扛过去就是质变。

### 第 6-7 周 · 指针（给足两周）

**第 6 周**
- 什么是指针、地址的概念、`%p` 打印地址
- `&` 取地址、`*` 解引用
- 指针变量的定义与初始化（**不初始化的指针是野指针**）
- 指针的大小与类型
- 通过指针修改外部变量

**第 7 周**
- 指针运算：`p+1` 到底加了几字节
- 指针与数组的关系：`arr[i]` ≡ `*(arr+i)`
- 指针数组 vs 数组指针（`int *p[3]` vs `int (*p)[3]`）
- 二级指针
- 函数指针（回调机制的基础，RTOS 里满地都是）

**练习**
- 用指针重写阶段一所有程序
- 用指针实现 `strlen / strcpy`
- 用函数指针实现通用排序（类似 `qsort`）

**⚠️ 自检（这几个答不出，就别进下一周）**
1. `int *p[3]` 和 `int (*p)[3]` 内存上分别是什么？
2. `char *p = "hello"; p[0] = 'H';` 为什么崩溃？
3. 函数参数传数组，传过去的是什么？

---

### 第 8 周 · 内存布局与动态分配

**任务**
- 程序内存分区：栈、堆、`.data`、`.bss`、代码段、常量区
- `malloc / calloc / realloc / free`
- **每次 `malloc` 后必须判空**
- 内存泄漏、野指针、重复释放、释放后未置空
- `const` 与指针的四种组合
- 大数组放栈上会爆栈（栈通常只有几 KB）

**练习**
- 动态创建数组并释放
- 用 valgrind 或 `-fsanitize=address` 检查自己写的程序
- 故意写一个内存泄漏，然后用工具把它找出来

**⚠️ 铁律**
- `malloc` 和 `free` 必须配对，且不能重复 `free`
- `free(p)` 之后立刻 `p = NULL`
- 不要返回局部变量的地址

---

### 第 9 周 · 结构体深入与链表

**任务**
- 结构体内存对齐（面试高频，要会手算 `sizeof`）
- 联合体、枚举、位域
- `typedef` 的使用
- 单向链表：创建、插入、删除、查找、销毁
- 双向链表、循环链表

**练习**
- 实现完整的单向链表库
- 用链表实现栈和队列
- 手算几个结构体的 `sizeof`，然后用程序验证

---

### 第 10 周 · 位运算与预处理

**任务**
- 位运算：`& | ^ ~ << >>`
- 寄存器操作三件套：置位、清位、取位
- `#define`、带参宏、**宏的副作用**（经典坑：`#define SQR(x) x*x` 遇到 `SQR(a+1)`）
- 条件编译、头文件防重复包含
- `#include` 的搜索路径

**练习**
- 用宏实现寄存器位操作：`SET_BIT / CLEAR_BIT / READ_BIT`
- 用位运算实现：判断奇偶、交换两数、统计 1 的个数
- 写出 `#define MAX(a,b)` 的安全写法并解释每一层括号的作用

---

### 第 11 周 · 文件 IO 与多文件工程

**任务**
- `fopen / fclose / fread / fwrite / fprintf / fscanf`
- 文本模式与二进制模式的区别
- `argc / argv` 命令行参数
- `.h` 与 `.c` 的划分原则：头文件放声明，源文件放实现
- `static` 隐藏内部符号、`extern` 声明外部符号
- Makefile 基础
- gdb 单步调试、断点、查看变量与内存

**练习**
- 把前几周的链表、ring buffer 整理成规范的库工程（多个 `.c` + `.h` + Makefile）
- 写一个简单的日志模块

### 阶段二验收
独立实现 **ring buffer** + **通用链表（`void*` 数据 + 函数指针回调）**，并配自己的测试用例。

## 七、推荐项目

选一个做深做透，**标准是能回答"为什么这么设计"**：

| 项目 | 内容 | 优势 |
|------|------|------|
| **多通道数据采集系统** ⭐ | ADC 多路 + DMA + 串口上传 + 上位机显示 | 测控对口，能体现信号链理解 |
| 环境监测终端 | 温湿度/气压 + OLED + 低功耗 + SD 卡记录 | 综合性强，外设覆盖全 |
| 简易示波器 | 高速 ADC + 定时器触发 + 波形显示 | 测控 + 信号处理双重加分 |
| CAN 采集节点 | CAN 通信 + 协议解析 | 汽车电子方向敲门砖 |

**面试官会追问的典型问题**（答不上来 = 项目白做）：
- 这里为什么用中断而不是轮询？
- DMA 传输时 CPU 在干什么？
- 如果采样率翻倍，你要改哪些地方？
- 数据丢包了你怎么排查？

## 八、每天 2 小时怎么分配

**建议拆成两段，不要一口气 2 小时**（零基础容易疲劳、效率断崖下跌）：

| 时段 | 内容 | 时长 |
|------|------|------|
| 第 1 段 | 看教程/教材，理解概念，做笔记 | 40 min |
| 第 2 段 | **关掉教程和 AI，自己写代码**（最重要） | 60 min |
| 碎片 | 纸笔推演 / 朗读代码 / 复盘今天踩的坑 | 20 min |

**铁律：第 2 段期间不许开 AI、不许看教程。** 卡住就卡住，卡住才是学习。

## 九、反 AI 依赖五条硬规矩

1. **15 分钟法则**：卡住憋满 15 分钟才准问 AI，且**只问思路不问代码**，问完关掉对话自己敲。
2. **三遍手敲法**：写通之后关掉编辑器重敲一遍，隔天再敲一遍。第三遍能不看提示敲出来，才算真会。
3. **纸笔推演法**：遇指针/数组/递归，拿纸画内存格子图，逐行写下变量值，再跑程序对答案。**对不上的地方就是你真正的缺口。**
4. **调试器替代 AI**：出 bug 不许直接贴给 AI。先用 `printf` 或 gdb 单步定位到具体哪行、哪个变量不对。
5. **代码朗读法**：每天挑 20 行自己写的代码，逐行讲出"这行在干什么、内存发生了什么"。讲不明白 = 没懂。

> **前两周你会非常痛苦**，敲十行错八行。这是正常的，说明训练生效了。撑过第三周会突然开窍。

## 十、避坑指南

1. **不要收藏教程当学过。** 收藏 100 个视频不如敲通 30 个程序。
2. **不要追求看完再动手。** 看一章写三道题，循环推进。
3. **不要跳过编译警告。** `-Wall -Wextra` 报的每一条都去弄懂。
4. **不要用 `strcpy` / `sprintf` / `gets`。** 用 `strncpy` / `snprintf`，记得手动补 `'\0'`。
5. **不要死记八股。** 先理解原理，八股只是把理解翻译成面试语言。
6. **简历上别写你讲不清的项目。** 之前 AI 做的项目，要么自己重做吃透，要么撤掉——三问必穿帮。
