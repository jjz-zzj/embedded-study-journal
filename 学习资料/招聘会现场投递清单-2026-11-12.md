## 4. 现场 30 秒开场（照实说，不主张没做过的事）

> 「我是中南大学测控技术与仪器 2027 届本科，想找**测试 / 验证 / 板级调试**方向的岗。C 语言我在从头系统学，现在能独立写到位操作、帧解析这一层，自己写的每一步调试都有记录。想先确认一下，这个岗是新人跟着师傅做验证，还是需要独立写驱动？」

配套三个必问（上午的教训：先搞清对方考什么）：
1. **岗位形态**：验证/测试为主，还是独立写驱动？有没有师傅带？
2. **流程**：有没有笔试/测评？什么形式、多长时间？
3. **材料**：是否核盖章成绩单？offer 是否写明需双证？

**别说**：不要主动抛 STM32/FreeRTOS/RTOS/Modbus/FOC 等名词；不要讲那两个 AI 代写项目；被问「自己调过什么」就讲 C 练习里真实做过的调试过程，讲不出就直说在补。

## 5. 出门前 3 分钟自检

- **简历只带 v4 版**，且当场改这 3 处：教育背景 `2027.07` → **`2027.06`**；技能栏删掉/降级无证据的 `C++ / FreeRTOS / STM32F1/F4 / Python / MATLAB / SPI`；期望薪资写「**按公司应届生统一标准**」。
- **别带** `简历-…-投递版.docx`、`简历-…-运控方向.docx`（含 AI/模板项目和未填占位符），这两份应加 `禁用-` 前缀归档。
- 不写 GPA / 排名 /「无挂科」/「全部通过」；被问成绩按固定口径答，不主动提。
