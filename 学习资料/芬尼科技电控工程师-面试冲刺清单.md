## 3. 速记卡（平板刷，可直接背）

### C 语言 / 驱动层地基
- `volatile`：告诉编译器**每次都从内存重新读**，用于硬件寄存器、中断服务程序里被改的全局标志、多线程共享变量。少了它，编译器优化会把值缓存到寄存器，读到的永远是旧值 → **必问题**
- 位操作四件套（P8）：
  ```c
  reg |=  (1U << n);      // 置位
  reg &= ~(1U << n);      // 清零（~ 不能漏）
  reg ^=  (1U << n);      // 翻转
  bit = (reg >> n) & 1U;  // 读第 n 位
  ```
- 寄存器映射：结构体 + 位域，配合 `volatile`
- `static`：局部变量保状态 / 全局量限制在本文件可见
- 宏必须加括号：`#define SET_BIT(x,n) ((x) |= (1U << (n)))`
- 补码：`INT_MIN = -2147483648`，`-INT_MIN` 会绕回自己（UB）；`UINT_MAX` 用 `%u` 打印，用 `%d` 会显示 -1
- 整数除法截断：`9/5 = 1`，`9.0/5 = 1.8`

### UART / RS485
- 帧：`1 起始位 + 8 数据位 + 可选校验 + 1 停止位`，典型 `9600-8-N-1`，波特率必须两端一致
- TTL：0/3.3V，板内短距；RS232：±3~15V、点对点、约 15m；**RS485：差分 A/B、抗共模干扰、多点、可达 1200m、两端 120Ω 终端电阻**
- 热泵为什么用 485：室外机与线控器距离远、产线干扰大、多台机组要挂同一条总线
- **调试手段（测控强项，JD 明确要）**：USB 转 485 + 串口助手看报文、示波器看 A/B 差分波形与位宽验证波特率、逻辑分析仪解帧、CRC 手工核对

### Modbus RTU
- 主从：只有主站发起，从站按地址应答；地址 1~247，0 = 广播
- 帧：`从站地址(1B) | 功能码(1B) | 数据(NB) | CRC16(2B, 低字节在前)`
- **分帧靠总线静默 ≥ 3.5 个字符时间**（RTU 无起始符，最常被问）
- 功能码：`01` 读线圈、`02` 读离散输入、`03` 读保持寄存器、`05` 写单线圈、`06` 写单寄存器、`10`（0x10）写多寄存器
- 例：读室温 `01 03 00 00 00 01 84 0A` → 应答 `01 03 02 00 19 CRC_L CRC_H`（0x0019 = 25℃）
- CRC16：多项式 0xA001，初值 0xFFFF；异常响应 = 功能码 `| 0x80` + 异常码
- Modbus TCP：以太网 + MBAP 头、去掉 CRC（链路层已校验）
- 寄存器与"点表"：温度、压力、设定值、故障码都映射到保持寄存器，调试就是对照点表读写

### IIC
- 两线 SCL/SDA，**开漏输出 + 上拉电阻（典型 4.7kΩ）**
- 起始：SCL 高时 SDA 下降沿；停止：SCL 高时 SDA 上升沿
- 每字节 9 个时钟：8 位数据 + 1 位 ACK/NACK
- 7 位地址 + 1 位 R/W；常见外设：EEPROM(AT24C02)、温湿度(SHT3x/BME280)、OLED
- 与 UART 区别：同步（有时钟）vs 异步（靠波特率）；IIC 板内短距，UART/485 板间长距

### STM32（方法论，不装实操）
1. 看原理图：确认引脚、电平、上拉、外设挂在哪
2. 查参考手册 / 数据手册：时钟使能、GPIO 复用、寄存器位定义
3. 写初始化 + 读写函数（寄存器或 HAL 两种方式）
4. 串口打印 + 示波器/逻辑分析仪验证波形与时序
5. 超时、错误标志、异常保护

> 说法："我没在 STM32 上做过完整项目，但流程我是清楚的，也知道驱动层最后是落到寄存器位操作上——这块我 C 语言位运算练过。"

### FOC 名词卡（只到这一层）
> "FOC 是永磁同步电机的磁场定向控制，用 Clarke/Park 变换把三相电流解耦成励磁分量和转矩分量，SVPWM 做调制，转子位置估算用来替代编码器；变频压缩机驱动会用到。我了解整体框架但没做过，是入职后的重点学习方向。"
