## 4. 投递顺序（照着点就行）

1. **银河电力**：发 `hr@inhegroup.com`，主题「姜俊哲+中南大学+测试工程师（硬件）」→ 全场最匹配，先发。
2. **格力**：`https://zhaopin.greeyun.com/home` 注册 → **先看完整职位列表再选 1 个**（限投 1 个），选技术支持/制造技术类里的测试验证岗。
3. **奔图**：`https://pantum.zhiye.com/` → 校园招聘 → 选「设备开发/打印机」，第二志愿填「电气工艺」；招满即止。
4. 有余力再投 **国星光电**（`https://gdrising.hotjob.cn`，研发工程师助理）→ **海悟**最后。

**投前统一确认三件事**（上午的教训）：这个岗是跟着师傅做验证还是独立写驱动？有没有笔试/测评？是否核盖章成绩单？
**别在一家公司同时投「测试」和「嵌入式软件」两个岗**——格力、奔图都限投 1 个，银河虽不限但今天只走测试层。

## 5. 看到完整名录里陌生公司时，30 秒判断法

按这个顺序扫 JD，任一不满足就跳过：

1. **学历**：写「硕士及以上」「硕博」→ 跳过。
2. **专业**：有没有「测控技术与仪器 / 自动化 / 电子信息 / 电气」→ 没有就跳过。
3. **岗位名**：含 测试 / 验证 / 可靠性 / 设备 / 工艺 / 质量 / 台架 → 可投；含 固件 / 驱动开发 / 底层 / 算法 → 今天不投。
4. **成绩条款**：搜「无挂科」「前 30%」「成绩优异」「GPA」→ 出现**硬性要求**立即停投；出现「…优先」记为减分项、降级处理。
5. **地域**：深圳 / 珠海 / 广州 / 东莞 / 佛山 / 长沙优先；其他标备选。
