P1 · 个人信息卡片

P2 · 类型字节数探测器
sizeof 是编译期运算符、%zu、limits.h
踩坑：%d 打 UINT_MAX 得 -1；-INT_MIN 绕回自己是 UB
P3 · 圆的几何计算
const double、整数除法截断、%.3f
踩坑：9/5 = 1；%.3f 与 %3f 的区别；PI 精度不够导致 6.284
P4 · 温度换算表
for 循环、off-by-one、列宽设计
收获：宽度 = 该列最长内容的字符数，宁可多不可少
P5 · 三数最大值
三目 ?: 是表达式、if 是语句
踩坑：声明要放块开头（C89 / Keil C51）；边界值 5 5 5
P6 · 简单计算器
switch / break / default / " %c"
踩坑：为检查返回值又多读一次 scanf，程序卡住等第四次输入
P7 · 成绩统计

唯一一次全对：预警的每个坑都避开了
P8 · 位操作
|= 置位 / &=~ 清零 / ^= 翻转 / >>n&1 读位
踩坑：else 里 return 0 让后面全不可达；scanf 又多读一次
加练 · 8 位寄存器调试台
功能码分发、进制格式化、0x%02X、×10 存温度、函数重构
坑：i>0 漏 bit0、循环次数用错变量、内外层共用 i、case 贯穿、\n 连漏六次

坑位地图 · 真正长本事的地方

10/26 – 11/06
类型与格式
%.2f → %f → %1f%d 打 UINT_MAX = -19/5 = 1%zu
同一块内存的两种解读、整数除法截断、格式符必须与类型严格对应。
11/07 – 11/08
输入与边界
scanf 多读一次else 里 return 0%19s 右对齐补空格
输入流是消费性的，检查返回值要就地做，不是再调一次函数。
11/09
结构与重构
i>0 漏最低位n / x 搞反内外层共用 i 死循环case 3 贯穿到 case 4\n 连漏六次C4244 / C4702 / C4189
循环边界、变量语义、共享状态被意外改写、switch fall-through、警告清零。

复习不是平均重做八题，而是按踩坑次数分配时间。跨题复发的坑（scanf 多读一次，P6 → P8）最该盯。
