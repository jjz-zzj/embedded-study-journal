## 第 1 章 · 计算机与编程语言（极速导读）

### 1. 核心思想（翁恺大白话）
* **计算机很笨，但算得极快**：计算机不会思考，它只会按部就班执行指令，它唯一的超能力就是“重复”。
* **什么是编译？**
  * 你写的代码是英文（源代码 `.c`），CPU 只认 `010101`（机器码）。
  * **编译器（Compiler）** 就像一个专业的翻译官，把你的 `.c` 代码一整本翻译成可执行文件 `.exe`。
* **为什么选择 C 语言？**
  * C 语言是操作系统（Linux/Windows）和**单片机/嵌入式**的通用语言，它离底层硬件内存最近，效率最高。

### 2. 视频里的第一个核心代码（骨架拆解）
```c
#include <stdio.h>  // 包含标准输入输出库（Standard Input/Output）

int main()          // 整个程序的入口点，CPU 上电后从 main 开始执行
{
    printf("Hello World!\n"); // 在终端屏幕打印文本，\n 表示换行
    return 0;                 // 返回 0 给操作系统，代表程序正常结束
}
```
> **⚠️ 新手高频坑点**：
> 1. 所有符号（括号、分号、双引号）必须是**英文半角**！误输入中文分号 `；` 编译器会疯狂报错。
> 2. `printf` 拼写不要漏掉字母 `f`（format 的意思）。
> 3. 每条执行语句末尾必须以英文分号 `;` 结尾。

## 第 2 章 · 计算与变量（核心精髓）

### 1. 核心概念：什么是变量？
* **翁恺经典比喻**：**“变量就是一个有名字的盒子”**。
  * `int price = 0;`：在内存里申请了一个可以放整数的盒子，贴上标签叫 `price`，并往盒子里放了个数字 `0`。
  * 变量有**三个要素**：名字、类型（装什么东西）、值（当前装了什么）。

### 2. 核心功能：读入数据（`scanf` 的底层逻辑）
* `printf` 是把盒子里的东西**拿出来给你看**。
* `scanf` 是**从键盘读取你敲的数字，放进盒子里**。

```c
#include <stdio.h>

int main()
{
    int price = 0; // 定义变量并初始化为 0（好习惯：必须赋初始值，防止里面是垃圾乱码）
    
    printf("请输入金额（元）：");
    scanf("%d", &price); // %d 表示读取一个十进制整数，&price 表示把数据塞进 price 这个盒子的内存门牌号里
    
    int change = 100 - price; // 计算找零
    
    printf("找您 %d 元。\n", change);
    
    return 0;
}
```

### 3. 翁恺重点强调的【四大致命踩坑点】
1. **`scanf` 漏写 `&`（初学者最常见错误，没有之一！）**
   * 错写：`scanf("%d", price);` &rarr; 程序直接闪退、崩溃！
   * 记住：只有带了 `&`，函数才知道去哪个内存地址改写盒子里面的值。
2. **`scanf` 双引号内不要乱加 `\n`**
   * 错写：`scanf("%d\n", &price);`
   * 后果：程序会一直卡住要求你再多敲一个字符才肯继续！双引号里只写纯格式说明符 `%d`。
3. **整数除法的坑（极重要！）**
   * 在 C 语言中，`10 / 3` 的结果是 **`3`**（直接把小数部分砍掉截断，不会四舍五入）！
   * 如果想得到带小数点的结果，必须至少有一个数带小数点：`10.0 / 3`，且变量类型需使用 `double` 或 `float`。
4. **变量必须先定义、再使用**
   * C99 标准允许在使用前随时定义变量，但定义之后才能拿来做算术运算。

## 3 分钟随堂动手小练习（直接在电脑上敲一下）

**题目（身高的英尺英寸换算）**：
编写一个程序，输入用户的身高厘米数（比如 175），将其换算为米（`1.75` 米）并打印。

**参考标准代码**：
```c
#include <stdio.h>

int main()
{
    printf("请输入身高(厘米)：");
    double cm = 0.0;
    scanf("%lf", &cm); // double 类型的格式说明符是 %lf (long float)
    
    double meter = cm / 100.0; // 注意用 100.0 做除法
    printf("您的身高是: %f 米\n", meter);
    
    return 0;
}
```
